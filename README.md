# Ultraverse NFT marketplace

Rebuilt from the FES-provided [NFT marketplace starter](https://github.com/hannamitri/nft-marketplace-starter) to match the [course reference](https://nft-marketplacee.web.app/).

Live: https://hyunguy.github.io/hyunclothingshopsite/

The original starter components, styles, fonts and images are retained. Vite provides the build and HashRouter allows deep links to refresh on GitHub Pages. Feature branches and pull requests implement the lessons in sequence; see the repository pull-request history. The earlier clothing implementation remains in Git history.

Run `npm ci`, `npm run dev`, `npm test`, and `npm run build` with Node 22+. GitHub Actions builds and deploys main.
